🔍 Key Features & Data Flow

📹 Recording Flow

1. User clicks extension icon or uses shortcut (Alt+Shift+L)

2. Service Worker requests desktop/tab capture permissions

3. MediaRecorder API captures video/audio streams

4. WebAssembly muxer processes media data

5. Upload to Loom servers via API

🌐 Site Integration

• Gmail: Inject compose buttons and video embeds

• Slack/GitHub: Add companion bubble for quick recording

• Google Docs/Figma: Context-aware recording features

• Link expansion for video previews on supported sites

🔐 Permissions

• desktopCapture: Screen recording access

• tabCapture: Browser tab recording

• storage: Save user preferences

• cookies: Authentication with Loom

• activeTab: Current tab interaction

⚡ Performance Features

• Virtual background processing (libvirtualbg)

• WebAssembly for media muxing

• AudioWorklet for real-time processing

• Redux for state management

• Lazy loading of components

🎮 User Controls

• Keyboard shortcuts for recording control

• Alt+Shift+C: Cancel recording

• Alt+Shift+R: Restart recording

• Alt+Shift+P: Pause/Resume

• Context menus for quick actions

📊 Data Processing

• Audio visualization with waveforms

• Video preview thumbnails

• Live rewind capabilities

• Blur and canvas effects

• Template overlays (meeting, standup, etc.)

🔄 Communication Flow

  1. User Interaction: Click extension icon or use keyboard shortcut
  2. Service Worker: Handles request, checks permissions, initializes capture
  3. Content Scripts: Inject UI components into active page if needed
  4. Media Capture: Chrome APIs (desktopCapture/tabCapture) + Web APIs (MediaRecorder)
  5. Processing: WebAssembly muxer, AudioWorklet for audio processing
  6. Storage: Temporary local storage during recording
  7. Upload: Stream to Loom servers via authenticated API calls
  8. Feedback: Update UI with recording status, preview, and share links
